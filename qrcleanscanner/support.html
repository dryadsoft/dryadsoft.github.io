2. 자주 묻는 질문 (FAQ)

  1. 카메라 스캔을 시작할 수 없어요. / I cannot start camera scanning.
    기기 설정에서 카메라 권한이 허용되어 있는지 확인하고, 다른 앱이 카메라를 사용 중이면 종료한 뒤 다시 시도해 주세요.
    Check that camera permission is allowed in device settings. If another app is using the camera, close it and try again.
  2. 코드가 인식되지 않아요. / The code is not recognized.
    QR 또는 바코드가 프레임 안에 들어오도록 맞추고, 조명이 부족하면 플래시를 켜거나 화면의 반사를 줄여 주세요.
    Place the QR or barcode inside the frame. If lighting is low, turn on the flashlight or reduce screen glare.
  3. 링크 열기 버튼이 비활성화되어 있어요. / The open link button is disabled.
    URL이 아닌 코드이거나 알 수 없는 스킴일 수 있습니다. 필요한 경우 원문 복사 또는 공유를 사용해 내용을 확인해 주세요.
    The result may not be a URL or may use an unknown scheme. Use copy or share to inspect the raw value when needed.
  4. 기록이나 메모가 보이지 않아요. / I cannot find history or notes.
    자동 저장 설정, 보관 기간, 타입 필터, 검색어를 확인해 주세요. 기록 삭제 또는 앱 저장공간 초기화 후에는 복구할 수 없습니다.
    Check auto-save settings, retention period, type filters, and search terms. Deleted history or cleared app storage cannot be restored.
  5. 이 앱이 링크 안전을 보장하나요? / Does this app guarantee link safety?
    아니요. 앱은 URL 구조와 확인 필요 플래그를 보여주지만 악성 여부, 피싱 여부, 안전성을 보장하지 않습니다. 링크 열기는 사용자가 직접 선택합니다.
    No. The app shows URL structure and check-needed flags, but it does not determine malware, phishing, or safety. Opening a link is always your choice.

앱은 스캔 기록, 즐겨찾기, 메모, 설정을 기기 안에 저장하며 계정 기반 서버 동기화나 서버 URL 평판 조회를 제공하지 않습니다. 결과를 공유하면 사용자가 선택한 외부 앱 또는 서비스의 정책에 따라 원문 또는 요약 내용이 처리될 수 있습니다.
