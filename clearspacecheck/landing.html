삭제 전에 큰 파일과 중복 후보를 공간 정리 체크(Clear Space Check)로 확인하세요.

큰 파일, 오래된 다운로드, APK, 중복 가능 사진과 영상을 로컬에서 스캔하고 삭제 전 미리보기와 삭제 후 리포트로 정리 결정을 돕습니다.

개인정보처리방침

공간 정리 체크(Clear Space Check)는 이렇게 삭제 전 확인을 돕습니다

▣

큰 파일과 다운로드 확인

기기에 저장된 큰 파일, 오래된 다운로드, APK 후보를 크기와 위치 요약으로 확인합니다.

◎

중복 사진/영상 후보 검토

중복 가능 사진과 영상을 검토용 후보로 묶어 보여주고 자동 삭제 대신 사용자가 직접 선택합니다.

✓

삭제 전 미리보기

삭제 요청 전에 파일 정보, 크기, 미리보기, 선택 상태를 다시 확인하도록 흐름을 분리합니다.

↺

정리 리포트와 히스토리

삭제됨, 건너뜀, 파일 없음, 실패 상태를 구분하고 정리 기록을 기기 안에 저장합니다.
