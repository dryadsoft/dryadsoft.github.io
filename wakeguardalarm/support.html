2. 자주 묻는 질문 (FAQ)

  1. 테스트 알림이 보이지 않아요. / I cannot see the test notification.
    Android 알림 권한, 앱 알림 채널, 방해금지 모드, 잠금화면 알림 설정을 확인해 주세요. 권한이 꺼져 있으면 알람 알림 탭이나 미션 진입이 제한될 수 있습니다.
    Check Android notification permission, app notification channels, Do Not Disturb, and lock-screen notification settings. If permission is off, alarm notification taps or mission entry may be limited.
  2. 소리나 진동이 들리지 않아요. / Sound or vibration does not work.
    알람 또는 미디어 볼륨, 진동 설정, 선택한 음악 파일 접근 가능 여부, 절전 제한 상태를 확인한 뒤 알람 전 테스트를 다시 실행해 주세요.
    Check alarm or media volume, vibration settings, selected music file availability, and battery restriction state, then run the pre-alarm test again.
  3. 정확 알람이나 전체화면 항목이 표시돼요. / Exact alarm or full-screen items appear.
    Android 버전과 제조사 정책에 따라 정확 알람, 전체화면 알림 후보, 배터리 최적화 설정이 다르게 보일 수 있습니다. 앱은 설정을 자동으로 변경하지 않으므로 안내된 기기 설정을 직접 확인해 주세요.
    Exact alarm, full-screen notification candidate, and battery optimization settings can differ by Android version and manufacturer policy. The app does not change these settings automatically, so review the guided device settings yourself.
  4. 미션 알림 열기 테스트가 없어요. / Mission notification open test is missing.
    미션 알림 열기 테스트는 선택된 알람이 있을 때만 보조 확인으로 표시됩니다. 알람을 저장하거나 선택한 뒤 다시 테스트해 주세요.
    The mission notification open test appears only as a secondary check when an alarm is selected. Save or select an alarm, then test again.
  5. 앱이 기상 성공을 보장하나요? / Does the app guarantee wake-up success?
    아니요. 앱은 알림, 소리, 진동, 절전 제한을 점검하고 문제를 줄이도록 돕지만 기상 성공을 보장하지 않습니다. 제조사 절전 제한, 권한 꺼짐, 기기 전원 상태에 따라 알람 동작이 제한될 수 있습니다.
    No. The app helps check notification, sound, vibration, and battery restrictions to reduce issues, but it does not guarantee wake-up success. Manufacturer battery restrictions, disabled permissions, and device power state can limit alarm behavior.

3. 개인정보 & 데이터 / Privacy & Data

앱은 알람 설정, 테스트 결과, 권한 점검 이력, 기상 미션 기록을 기기 안에 저장하며 계정 기반 서버 동기화는 제공하지 않습니다. 알림음으로 기기 음악 파일을 선택하거나 시스템 설정 화면으로 이동할 때는 운영체제 또는 사용자가 선택한 외부 앱의 정책에 따라 파일 참조나 설정 상태가 처리될 수 있습니다.
The app stores alarm settings, test results, permission check history, and wake mission records on device, and does not provide account-based server sync. When you choose a device music file as an alarm sound or move to system settings, file references or setting states may be processed under the OS or selected external app policy.
