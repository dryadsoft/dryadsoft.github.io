2. 자주 묻는 질문 (FAQ)

  1. 오늘 총량이 예상과 달라요. / Today's total does not match my expectation.
    기록 시간, 수량, 삭제된 항목을 확인해 주세요. 잘못 저장된 기록은 기록 화면에서 수정하거나 삭제할 수 있습니다.
    Check record time, amount, and deleted items. Incorrect records can be edited or deleted from the history screen.
  2. 직접 입력 수량을 바꾸고 싶어요. / I want to change a custom amount.
    직접 입력 화면에서 수량을 조정한 뒤 저장하세요. 기본 컵은 설정에서 바꿀 수 있습니다.
    Adjust the amount on the custom entry screen and save it. You can change the default cup in settings.
  3. 알림이 오지 않아요. / Reminders do not arrive.
    기기 알림 권한, 앱의 알림 on/off, 시작/종료 시간, 요일, 조용한 시간을 확인하세요.
    Check system notification permission, in-app reminder on/off, start/end time, weekdays, and quiet hours.
  4. 데이터를 다른 기기와 동기화할 수 있나요? / Can I sync data with another device?
    현재 물한잔 알림은 로컬 우선 앱이며 계정 기반 서버 동기화를 제공하지 않습니다.
    Sip Reminder is currently local-first and does not provide account-based server sync.

3. 개인정보 & 데이터 / Privacy & Data

앱은 물 기록, 컵 프리셋, 하루 목표, 알림 설정, 조용한 시간을 기기 안에 저장하며 계정 기반 서버 동기화를 제공하지 않습니다. 앱 설정의 로컬 데이터 삭제 기능으로 저장된 기록과 설정을 삭제할 수 있습니다.
The app stores water records, cup presets, daily goals, reminder settings, and quiet hours on device, and does not provide account-based server sync. You can delete saved records and settings with the local data deletion option in app settings.
