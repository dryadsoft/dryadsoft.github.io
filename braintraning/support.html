2. 자주 묻는 질문 (FAQ)

  1. 문제 보드와 기록은 어디에 저장되나요? / Where are boards and records stored?
    신규 문제 보드는 앱 실행 시 Supabase에서 확인한 뒤 기기 로컬 SQLite에 저장됩니다. 퀴즈 진행 상태, 출석 기록, 설정도 기기에 보관됩니다.
    New quiz boards are checked from Supabase on app launch and stored in local SQLite on the device. Quiz progress, attendance, and settings are also stored locally.
  2. 음성 입력이 늦거나 실패해요. / Voice input is delayed or fails.
    5초 이상 반응이 없으면 잠시 기다린 뒤 다시 시도해 주세요. 계속 어렵다면 키보드 입력 버튼으로 같은 문제를 이어서 풀 수 있습니다.
    If there is no response for more than 5 seconds, wait briefly and try again. If needed, switch to the keyboard input button and continue the same question.
  3. 글자가 작게 보여요. / The text looks too small.
    퀴즈 화면의 [+] [-] 배율 조절을 사용하거나 기기 접근성 설정에서 글자 크기를 키워 주세요.
    Use the [+] [-] zoom controls on the quiz screen or increase the device text size in accessibility settings.
  4. 문제를 불러오지 못했어요. / The app could not load quiz data.
    네트워크 연결을 확인한 뒤 다시 시도해 주세요. 같은 문제가 반복되면 오류 시점과 기기 정보를 함께 보내 주세요.
    Check your network connection and try again. If the issue repeats, send us the time of the error and your device details.
