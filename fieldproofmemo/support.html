2. 자주 묻는 질문 (FAQ)

  1. 사진을 첨부할 수 없어요. / I cannot attach photos.
    기기 설정에서 카메라와 사진 보관함 권한을 확인해 주세요. 작업 중에는 사진 품질 설정에 따라 파일 크기와 처리 시간이 달라질 수 있습니다.
    Check camera and photo library permissions in device settings. File size and processing time may vary depending on the photo quality setting.
  2. 위치 기록이 저장되지 않아요. / Location is not saved.
    위치 기록은 선택 기능입니다. 권한을 거부해도 보고서는 만들 수 있으며, 위치가 필요한 보고서만 권한을 허용한 뒤 다시 시도해 주세요.
    Location capture is optional. You can create reports without location permission. Grant permission and try again only for reports that need location.
  3. PDF 생성 또는 공유가 실패해요. / PDF generation or sharing fails.
    사진 수와 품질이 높으면 PDF 생성 시간이 길어질 수 있습니다. 사진 품질을 낮추거나 기기 저장공간을 확인한 뒤 다시 생성해 주세요.
    PDF generation can take longer with many high-quality photos. Lower photo quality or check device storage, then try again.
  4. 데이터를 다른 기기와 동기화할 수 있나요? / Can I sync data with another device?
    현재 현장 증빙 메모는 로컬 우선 앱이며 계정 기반 서버 동기화를 제공하지 않습니다.
    Field Proof Memo is currently local-first and does not provide account-based server sync.

3. 개인정보 & 데이터 / Privacy & Data

앱은 현장 보고서, 사진, 체크리스트, 선택형 위치, 설정을 기기 안에 저장하며 계정 기반 서버 동기화는 제공하지 않습니다. PDF를 공유하면 사용자가 선택한 외부 앱 또는 서비스의 정책에 따라 파일이 처리될 수 있습니다.
The app stores field reports, photos, checklists, optional location, and settings on device, and does not provide account-based server sync. When you share a PDF, the selected external app or service may process the file under its own policy.
