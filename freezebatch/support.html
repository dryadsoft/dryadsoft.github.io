Freeze Batch는 집에서 만드는 냉동 디저트의 레시피와 식감을 기록하는 앱입니다. 현재 Google Play와 App Store 출시를 준비하고 있습니다. 아래 안내는 출시 준비 버전 1.0.0을 기준으로 합니다.

Freeze Batch records recipes and textures for frozen desserts made at home. It is preparing for release on Google Play and the App Store. The guidance below describes the launch-preparation version 1.0.0.

1. 문의하기 / 1. Contact support

지원 이메일은 dryadsoft@gmail.com입니다. 앱 버전, 기기 모델, OS 버전, 문제가 발생한 화면과 재현 순서를 알려 주세요. 앱 설정의 문의하기로 메일 초안을 열면 지원 ID와 기본 기기 정보가 포함되며, 전송 전 수정할 수 있습니다.

Our support email is dryadsoft@gmail.com. Please include your app version, device model, OS version, the affected screen and steps to reproduce the issue. Contact support in the app’s Settings opens a draft containing the Support ID and basic device details, which you can edit before sending.

메일 앱이 열리지 않으면 메일 계정 설정을 확인하거나 아래 주소로 직접 보내 주세요. 레시피·개인 메모·비밀번호는 보내지 않아도 됩니다. 화면을 첨부할 때는 공개하고 싶지 않은 내용을 가려 주세요.

If your email app does not open, check its account settings or email the address below directly. You do not need to send recipes, private notes or passwords. Hide any information you do not want to share before attaching a screenshot.

dryadsoft@gmail.com

2. 다음 버전을 만들 수 없어요 / 2. I cannot create the next version

같은 실험의 최신 배치를 완료해야 다음 버전을 만들 수 있어요. 진행 중인 배치가 있다면 준비 → 냉동 → 회전 가공 → 완료 순서로 이어서 기록하세요. 첫 배치에는 직전 결과가 없어 비교 화면이 제공되지 않아요.

Complete the latest batch in the same experiment before creating its next version. If a batch is in progress, continue through preparation, freezing, processing and completion in order. The first batch has no previous result to compare against.

3. 이전 레시피 값이 그대로 저장되지 않아요 / 3. Previous recipe values are not saved automatically

이전 값은 참고용이에요. 이번에 실제로 쓴 값을 입력한 변수만 이번 버전에 저장돼요. 값을 비워 두면 이번 기록에서 제외되며, 변수 이름과 현재 값이 적어도 한 쌍 필요해요. 동일한 값을 입력하면 같은 레시피로 다시 만든 기록을 남길 수 있어요.

Previous values are shown as a reference. Only variables for which you enter a current value are saved in the new version. A blank current value leaves that variable out, and at least one variable name and current value are required. Entering the same values records another trial of the same recipe.

4. 기록을 이어 쓰거나 저장하고 싶어요 / 4. Resuming and saving records

저장한 미완료 배치는 홈이나 버전 기록에서 다시 열어 이어서 작성할 수 있어요. 홈에 다른 실험이 보이면 배치 목록에서 원하는 실험을 찾고 홈에 표시를 선택하세요. 목록을 여는 것만으로 홈의 선택이 바뀌지는 않아요.

Reopen a saved, unfinished batch from Home or Version History to continue. If Home shows another experiment, find the one you want in the batch list and choose Show on Home. Opening a list alone does not change the selection on Home.

저장에 실패하면 입력 내용을 유지한 채 다시 시도하세요. 기기 저장공간과 필수 입력값을 확인해 주세요. 저장하지 않은 입력을 잃을 수 있으니 앱을 제거하거나 앱 데이터를 지우는 방법으로 해결하지 마세요.

If saving fails, keep your entered values and try again. Check available device storage and required fields. Do not troubleshoot by uninstalling the app or clearing its data, as this may lose your records.

5. 완료 기록을 수정하거나 삭제할 수 있나요? / 5. Can I edit or delete completed records?

완료한 배치는 수정할 수 없어요. 바꾼 레시피로 실험하려면 최신 완료 배치에서 다음 버전을 만드세요. 삭제는 배치 하나가 아니라 실험 전체 단위로 제공돼요. 설정의 모든 기록 삭제를 사용하면 모든 실험과 버전이 지워지며 복구할 수 없어요.

Completed batches cannot be edited. To try a changed recipe, create the next version from the latest completed batch. Deletion removes a whole experiment rather than a single batch. Clear all records in Settings removes all experiments and versions and cannot be undone.

6. 기기를 바꾸면 기록을 옮길 수 있나요? / 6. Can I move records to another device?

현재 계정, 클라우드 동기화, 파일 내보내기, 앱 자체 백업·복원은 제공하지 않아요. 기록은 해당 기기에 저장돼요. 앱 제거, 앱 데이터 삭제나 기기 변경 전에 필요한 기록을 별도로 남겨 주세요. Dryadsoft에서 기록을 복구할 수는 없어요.

Accounts, cloud sync, file export and in-app backup or restore are not currently available. Records are stored on that device. Keep a separate record of anything you need before uninstalling, clearing app data or changing devices. Dryadsoft cannot recover lost records.

7. 광고와 사용 분석 설정은 어디에 있나요? / 7. Where are advertising and analytics settings?

Google에서 변경 화면을 제공해야 하는 경우 설정에 광고 개인정보 설정이 표시돼요. iOS 추적 권한과 Android 광고 식별자 설정은 기기 설정에서 관리하세요. 광고를 불러오지 못해도 기록 기능은 사용할 수 있어요.

Advertising privacy options appear in Settings when Google requires this entry point. Manage iOS tracking permission and Android advertising identifier settings through your device settings. Recording features remain available if ads cannot load.

현재 사용 분석은 항상 켜져 있으며 별도의 끄기 기능은 없어요. 광고 설정 변경이나 모든 기록 삭제는 이미 전송된 분석 데이터의 삭제를 요청하지 않아요. 수집 항목과 보관·삭제 범위는 개인정보처리방침에서 확인하세요.

Usage analytics is currently always enabled, with no separate opt-out. Changing ad settings or clearing all records does not request deletion of analytics already transmitted. See the privacy policy for data categories, retention and deletion details.

8. 화면 테마를 바꾸고 싶어요 / 8. Changing the display theme

설정의 화면 테마에서 라이트 모드나 다크 모드를 선택하세요. 앱은 시스템 글자 크기를 지원해요. 글자가 잘리거나 버튼을 누르기 어렵다면 사용 중인 글자 크기와 해당 화면을 문의로 알려 주세요.

Choose light or dark mode under Display theme in Settings. The app supports the system text size. If text is clipped or a button is hard to use, tell support which text size and screen you are using.
