2. 자주 묻는 질문 (FAQ)

  1. 종목 검색 결과가 나오지 않아요. / Security search returns no results.
    국내 종목 검색은 네트워크 연결과 검색 서비스 상태의 영향을 받을 수 있습니다. 기본 목록에서 선택하거나 직접 입력으로 등록해 주세요.
    Korean security search may depend on network connection and search service availability. Try the built-in list or register the security manually.
  2. 배당 금액이 예상과 달라요. / Dividend totals do not match my expectation.
    예상 배당은 배당락일 이전 보유 수량과 입력한 주당 배당금을 기준으로 계산합니다. 거래일, 배당락일, 지급일, 통화가 올바른지 확인해 주세요.
    Estimated dividends are calculated from holdings before the ex-dividend date and the entered amount per share. Check the trade date, ex-dividend date, payment date, and currency.
  3. 알림을 켰는데 배당 알림이 오지 않아요. / Dividend reminders do not arrive.
    기기 알림 권한, 앱의 전체 알림 토글, 배당락일/지급일 알림 토글을 확인하세요. 이미 지난 오전 9시 기준 알림은 새로 예약되지 않을 수 있습니다.
    Check system notification permission, the main in-app notification toggle, and the ex-dividend/payment reminder toggles. Reminders whose 9:00 AM schedule has already passed may not be newly scheduled.
  4. 데이터를 다른 기기와 동기화할 수 있나요? / Can I sync data with another device?
    현재 배당노트는 로컬 중심 앱이며 계정 기반 서버 동기화를 제공하지 않습니다.
    Dividend Note is currently local-first and does not provide account-based server sync.

3. 개인정보 & 데이터 / Privacy & Data

앱은 보유 종목, 거래 이력, 배당 이벤트, 알림 설정을 기기 안에 저장하며, 계정 기반 서버 동기화는 제공하지 않습니다. 국내 종목 검색을 사용할 때에는 검색 처리를 위해 필요한 요청이 외부 서비스로 전송될 수 있습니다.
The app stores holdings, trade records, dividend events, and reminder settings on device, and does not provide account-based server sync. Korean security search may send necessary requests to an external service.
