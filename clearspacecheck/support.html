2. 자주 묻는 질문 (FAQ)

  1. 스캔을 시작할 수 없어요. / I cannot start a scan.
    Android 사진 및 동영상 접근 권한이나 선택한 파일/폴더 접근 범위를 확인해 주세요. 제한된 접근 상태라면 선택한 항목만 표시될 수 있습니다.
    Check Android photo and video permissions or the selected file or folder access scope. If access is limited, only selected items may appear.
  2. 모든 파일이 보이지 않아요. / Not every file appears.
    운영체제 권한, MediaStore 인덱싱 상태, SAF 선택 범위, 파일 위치에 따라 앱이 확인할 수 있는 항목만 표시됩니다. 앱은 `MANAGE_EXTERNAL_STORAGE` 권한을 사용하지 않습니다.
    Depending on OS permissions, MediaStore indexing, SAF selection scope, and file location, only items available to the app may appear. The app does not use the `MANAGE_EXTERNAL_STORAGE` permission.
  3. 중복 후보가 정확하지 않아요. / Duplicate candidates are not exact.
    중복 후보는 삭제를 자동 결정하지 않는 검토용 단서입니다. 파일을 삭제하기 전 미리보기와 정보를 직접 확인해 주세요.
    Duplicate candidates are review signals and do not automatically decide deletion. Review previews and details before removing any file.
  4. 삭제 요청이 실패했어요. / A delete request failed.
    Android 시스템 삭제 확인, SAF 권한 범위, 파일 이동/삭제 상태, 외부 저장소 연결 상태를 확인한 뒤 다시 시도해 주세요.
    Check Android system delete confirmation, SAF permission scope, whether the file was moved or already deleted, and external storage connection state, then try again.
  5. 확보된 저장공간이 예상과 달라요. / Recovered storage differs from the estimate.
    앱은 삭제 전 후보 크기와 삭제 후 확인 가능한 결과를 분리해서 보여줍니다. 운영체제 캐시, 미디어 인덱싱, 파일 시스템 반영 시점에 따라 기기 설정의 표시값은 다를 수 있습니다.
    The app separates pre-delete candidate size from results that can be checked after deletion. OS cache, media indexing, and file system update timing may make device settings show different values.

3. 개인정보 & 데이터 / Privacy & Data

앱은 스캔 결과, 삭제 후보 상태, 정리 기록, 설정을 기기 안에 저장하며 계정 기반 서버 동기화는 제공하지 않습니다. 시스템 삭제 확인, SAF, 공유 흐름을 사용할 때는 운영체제 또는 사용자가 선택한 외부 앱의 정책에 따라 파일이나 요약 내용이 처리될 수 있습니다.
The app stores scan results, delete candidate state, cleanup history, and settings on device, and does not provide account-based server sync. When you use system delete confirmation, SAF, or share flows, the OS or selected external app may process files or summary content under its own policy.
