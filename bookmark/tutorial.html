북마크 앱 사용 방법

북마크는 링크를 폴더별로 정리하고, 백업과 복원 기능까지 제공하는 스마트한 북마크 관리 앱입니다.

링크 폴더 생성

1. 폴더 추가

➕ 버튼을 눌러 새 폴더를 만드세요.

웹페이지 링크 추가

1. 웹 검색

브라우저 아이콘을 눌러 관련 ,링크를 검색하세요.

2. 브라우저 메뉴 열기

브라우저 오른쪽 상단 ⋮ 메뉴 버튼을 눌러 브라우저 메뉴를 펼치세요.

3. 공유 메뉴 선택

공유 버튼을 눌러 앱을 선택하세요.

4. 북마크 선택

공유 대상 목록 중 북마크 앱 아이콘을 선택하세요.

5. 링크 등록

링크를 추가할 폴더를 선택하세요.

등록 버튼을 눌러 링크를 추가하세요.

백업 및 복원

1. 설정에서 백업/복원

⚙️ 설정에서 백업 및 복원 메뉴를 선택하세요.

데이터를 안전하게 저장하거나 복원할 수 있습니다.
