TripNote 앱 사용 방법

TripNote는 여행 일정 작성, 사진 기록, 알림 설정까지 지원하는 스마트한 여행 앱입니다.

여행 시작하기

1. 여행 추가

➕ 버튼을 눌러 여행을 추가하세요.

2. 일정 상세 화면으로 이동

여행 카드를 눌러 일정 상세 ,화면으로 이동하세요.

일정 추가 및 관리

1. 일정 추가

➕ 버튼을 눌러 일정을 추가하세요.

2. 장소 추가

📍 버튼을 눌러 장소을 추가하세요.

3. 링크 추가

🔗링크추가 버튼을 눌러 링크를 추가하세요.

4. 알람 추가

⏰알람추가 버튼을 눌러 알람을 추가하세요.

링크 폴더 관리

1. 링크 폴더 추가

➕ 버튼을 눌러 링크 폴더를 추가하세요.

웹페이지 링크 추가

1. 웹 검색

브라우저 아이콘을 눌러 관련 ,링크를 검색하세요.

2. 브라우저 메뉴 열기

브라우저 오른쪽 상단 ⋮ 메뉴 버튼을 눌러 브라우저 메뉴를 펼치세요.

3. 공유 메뉴 선택

공유 버튼을 눌러 앱을 선택하세요.

4. 트립노트 선택

공유 대상 목록 중 TripNote 앱 아이콘을 선택하세요.

5. 링크 등록

링크를 추가할 폴더를 선택하세요.

등록 버튼을 눌러 링크를 추가하세요.
